# 范围与关键词

## 1. 词族

| 词族 | 关键词 |
|---|---|
| ESG | ESG、ESG 报告、ESG 咨询、ESG 评级、ESG 体系、ESG 披露、ESG 培训、ESG 管理 |
| 可持续发展 | 可持续发展报告、可持续发展规划、社会责任报告、CSR、企业社会责任、可持续披露 |
| 双碳 | 双碳、碳达峰、碳中和、碳排放、碳核查、碳盘查、碳核算、碳足迹、碳资产、碳交易、碳市场、碳排放权、CCER、温室气体、碳汇、零碳、低碳、碳捕集、CCUS、气候投融资 |
| 相关延伸 | 绿色工厂、绿色园区、绿色供应链、零碳工厂、零碳园区、能源审计、能源管理体系、清洁生产审核、转型金融、绿色金融 |

## 2. 排除规则

标题命中关键词，但属于下列情况之一的，不是 ESG 项目，剔除：

- 带的是物质或材料名：活性炭、碳酸锂、碳酸钙、碳酸钠、碳酸纤维、碳素、碳电极、碳刷、碳带、碳粉、碳化硅、碳化硼、碳分子筛、碳钢、低碳钢、高碳钢、碳罐、渗碳、脱碳层、增碳剂、炭黑。
- "二氧化碳"指气体采购、消防、食品加工。只有与"排放、捕集、封存、核算、清单"连用时才算。
- "低碳"修饰的是产品品类，如低碳钢、低碳饮食、低碳水，而不是项目主题。
- "社会责任"出现在非招标类文稿里，如年度总结、领导讲话。
- 关键词只出现在资质要求或正文里，标题和项目主题与 ESG 无关。
- 设备、耗材、软件采购，且项目主题不是碳管理和 ESG 服务的。

## 3. 项目类型

`project_type` 取值：

| 取值 | 典型项目 |
|---|---|
| ESG报告编制 | ESG、可持续发展、社会责任报告的编写、翻译、版式设计 |
| ESG咨询与体系 | ESG 战略规划、体系建设、评级提升、培训、鉴证准备 |
| 碳核查与盘查 | 温室气体排放核算与核查、碳盘查、碳足迹核算 |
| 双碳规划 | 碳达峰方案、碳中和路径、零碳园区与零碳工厂规划 |
| 碳资产与交易 | 碳资产管理、CCER 开发、碳金融 |
| 数字化平台 | 碳管理平台、ESG 数据平台、数据库采购 |
| 绿色认证 | 绿色工厂、绿色园区、绿色供应链创建咨询 |
| 能源与节能 | 能源审计、节能诊断、能源管理体系、清洁生产审核 |
| 其他 | 无法归入以上类型 |

## 4. 通知类型

- `award`：中标结果公告、成交公告、中选结果公告。候选人公示阶段金额可能未定，要在备注里说明。
- `tender`：招标公告、竞争性磋商、竞争性谈判、询价、单一来源采购公示、招标预告。

## 5. 采购人类型

| 取值 | 识别方法 |
|---|---|
| 政府机关 | 名称含局、委、办、人民政府 |
| 事业单位 | 名称含学校、医院、研究中心、中心、馆、院 |
| 国企 | 名称含集团、有限公司，且为央企或地方国企 |
| 金融机构 | 银行、证券、保险、基金、信托 |
| 企业 | 其余企业，所有制不明的也归这里 |
