# 信源与检索式

## 1. 检索式怎么写

- 每次检索约 6 条，要按角度切细。
- 时间写具体月份或年份："2026年11月"、"2025年"、"2024年"。不要写"本周""最近"，搜索会忽略。
- 不要用 `site:`，会让搜索报错。
- 带"可持续发展报告""规划""CCER""绿色工厂"的词容易返回政策文件，后面要跟"中标公告""成交公告""招标公告"这类通知类型词。

## 4. 信源清单

| 类型 | 信源 | 用法 |
|---|---|---|
| 政府采购 | 中国政府采购网及各省市采购网 | 政府机关、事业单位的 ESG 与双碳服务项目 |
| 公共资源交易 | 全国公共资源交易平台及各省市平台、招标代理机构官网 | 国企与政府项目的招标和结果公告 |
| 企业自采 | 上市公司官网"招标采购"栏目、央企电子招标平台 | 企业 ESG 报告编制、碳核查项目 |
| 行业聚合 | 工程招标网、寻标宝、千里马、采招网、剑鱼标讯 | 只做线索，金额与中标人以公告原文为准 |
| 财经媒体 | 新浪财经的"中标"类稿件 | 线索与金额旁证 |

## 5. 取证优先级

1. 招标人或招标代理机构官网的结果公告。
2. 政府采购网、公共资源交易平台公告。
3. 企业官网招标栏目。
4. 聚合站、行业号。只做线索或金额旁证。

## 6. 注意

- 一条结果里出现多个项目时，拆成多条记录，记录各自的来源。
- 金额单位以公告为准，统一换算成万元写入 `amount_wan`。
- 聚合站的页面常显示"中标金额 0.0 万"，这是未抓到金额，不是真实金额，按"未披露"处理。
