# 检索手册

## 1. 客户画像（客户不是中国神华时先做）

用三次检索建立画像，结果写入 `trace.md` 的"客户画像"：

- `<客户> 主营业务 所属行业 上市`：行业、上市地。上市地决定适用哪套披露规则。
- `<客户> ESG 实质性议题 ESG 评级`：重点议题、当前评级。
- `<行业> 龙头 可比公司`：对标企业 5–8 家，国内 3–5 家、国际 2–3 家，含控股股东集团。

## 2. 检索式矩阵

`{月}` 写成"2026年11月"这样的具体月份。每次检索约返回 6 条，所以检索式要窄：多换角度搜，不要指望一条检索式覆盖整章。

### 2.1 政策与监管

### 2.2 权威栏目页扫描（政策章节必做）

栏目页按时间倒序列出标题和日期，是找"时间窗内新政策"最可靠的办法。每个栏目页只读一次，读取计入网页读取预算。只挑时间窗内、与 ESG、双碳、环保、安全、披露有关的条目。

| 栏目 | 地址 |
|---|---|
| 生态环境部 政策文件（多栏目汇总） | https://www.mee.gov.cn/zcwj/ |
| 国务院国资委 中央企业动态 | http://www.sasac.gov.cn/n2588025/n2643314/index.html |
| 国家发展改革委 新闻发布 | https://www.ndrc.gov.cn/xwdt/xwfb/ |
| 财政部 政策发布 | https://www.mof.gov.cn/zhengwuxinxi/zhengcefabu/ |
| 生态环境部 新闻发布 | https://www.mee.gov.cn/ywdt/xwfb/ |
| 中国人民银行 新闻发布 | http://www.pbc.gov.cn/goutongjiaoliu/113456/113469/index.html |

先读前三个。政策章证据不足时再读其余的。工业和信息化部和中国证监会的栏目页无法直接读取，这两个部门只靠检索。

栏目页里命中的条目，尽量再打开对应的正文页核实；预算不够时保留列表页作为来源，并在核实方式里写"栏目页"。

## 3. 来源优先级

1. 一手原文：部委、交易所、公司、评级机构的官网与官方公告。
2. 权威媒体：新华社、人民网、中国证券报、上海证券报、证券时报、财新、第一财经、新浪财经、界面新闻。
3. 行业媒体与专业机构：行业报、协会、ESG 专业服务机构。
4. 聚合站与自媒体账号：只做线索，必须追到一手或权威媒体才能进正文。

## 4. 内置搜索的已知特性

- 每次约 6 条结果，多数带发布时间，但可能是"3天前"这样的相对时间，要按今天换算。
- 不要用 `site:`，会直接报错。把站点名或机构名写进关键词。
- 同一个主题换时间词（"2026年11月"、"11月"、"本周"）往往得到不同结果。
- 网页读取可能失败，也可能整页返回很长内容。只读高价值页面，并在请求里写明要提取的内容。

## 5. 剔除规则

| 情况 | 处理 |
|---|---|
| 日期在时间窗外 | 不进正文。确需作背景的放附录"背景资料" |
| 只有转载稿、找不到一手 | 可进正文，标注"未追溯一手" |
| 标题与内容不符、聚合页没有正文 | 不采信 |
| 同一事件多源报道 | 合并成一张卡，保留一手 URL |
| 传言、未经公告的消息 | 不采信 |
| 与 ESG 或客户议题无关 | 不采信 |
