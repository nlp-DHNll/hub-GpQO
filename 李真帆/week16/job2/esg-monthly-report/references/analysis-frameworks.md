# 分析框架

## 1. 政策与监管

逐条回答四问，答案写进表格的"核心内容"和"与客户的关联"，再展开成说明。

1. 义务变了什么：新增强制要求、时间节点、口径变化。
2. 是否适用于客户：有没有点名煤炭、煤电行业，央企，A+H 上市公司。
3. 影响在哪：合规成本、资本开支、披露工作量、融资条件、经营许可，哪一项受影响，量级多大。
4. 现在要做什么：合规动作、披露动作、对内分工、对外沟通。

写法示例：

> 生态环境部 X 月 X 日发布《……》，要求……，自 X 年 X 月起施行 [S3]。客户所属煤电行业被直接纳入。判断：高。建议：安全环保部在生效前完成排放数据口径切换，董事会办公室评估可持续发展报告相关章节的修订。

## 2. 评级与标准

- 评级变动：哪家机构、原级别与新级别、公布时间、报道给出的原因；对融资成本、指数纳入、投资者预期的影响；优先补哪一项。
- 标准更新：新增或修订了什么、何时生效、与客户现有披露口径差在哪里、需要补哪些数据和流程。

## 3. 行业动态

- 事件类型：安全事故、产能与价格政策、技术路线、同行处罚、行业倡议、协会标准。
- 分析路径：事件，波及范围，对客户的成本、许可、声誉、竞争位置的影响。
- 最佳实践案例卡：谁、做了什么、可量化的效果、客户能否复用、复用的条件。

## 4. 公司动态

事件，对应的 E、S、G 议题，正面或负面影响及量级，是否需要披露或回应，建议（主动披露、澄清说明、整改、明确责任部门）。

## 5. 对标分析

行动表列：企业、行动、类型（治理、目标、披露、投资、退出）、释放的信号、与客户的差距、可借鉴点。

表后写 3–5 句结论：客户在同业中的相对位置，最值得跟进的两三件事。

## 6. 影响等级

| 等级 | 判定条件 |
|---|---|
| 高 | 直接改变客户的合规义务，或带来重大财务、经营、声誉影响 |
| 中 | 间接影响客户，或需要提前准备、调整披露 |
| 低 | 方向性信号、行业趋势，关注即可 |

## 7. 行动建议

每条包含四项：动作、责任方向、时间、优先级。

- 责任方向：董事会办公室、安全环保、财务、投资者关系、战略规划、人力资源。
- 优先级：P1 本月内、P2 本季度内、P3 持续跟进。
