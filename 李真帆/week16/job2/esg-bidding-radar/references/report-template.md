# 回顾报告模板

按下面的骨架写 `body.md`，替换花括号内容，删掉用不到的示例行。不要写来源附录：合成时 render.py 会按 sources.jsonl 自动追加。图表用 `![说明](charts/xxx.png)` 引用脚本生成的图。

```markdown
# ESG 相关招投标回顾报告

**统计区间：** {起} 至 {止}　|　**出具日期：** {YYYY-MM-DD}　|　**样本：** 中标记录 {n} 条，其中披露金额 {n} 条

> **结论**：{两到三句，说清热点在哪里、钱花在哪、谁在赢}

## 一、样本说明

- 关键词范围：ESG、可持续发展、双碳三类词族，排除规则见附录。
- 检索 {n} 次，命中 {n} 条，去重后 {n} 条。其中中标类 {n} 条，招标类 {n} 条。
- 样本来自公开检索，不是全量。金额统计只基于披露了金额的记录。
- 打开原文核实 {n} 条，仅依据摘要 {n} 条。

## 二、总体情况

| 指标 | 数值 |
|---|---|
| 中标记录数 | |

| 金额合计（万元） | |

| 最大单笔（万元） | （附项目名） |

## 三、热点主题

本章最值得关注的是：{一句话}。

| 项目类型 | 条数 | 金额合计（万元） | 均值（万元） | 典型项目 |
|---|---|---|---|---|

说明哪两类最热，购买方主要是谁。

## 五、时间与地域

- 省份前 10。

```

## 写作规则

1. 先结论，再数据。
2. 每个数字都能在 `bids.csv` 里找到对应的行，引用时标 `[S#]`。
3. 样本不足的地方直接写"样本不足"，不外推。
4. 表格单元格写短句。
5. 不写"赋能""抓手""闭环"这类空词。
