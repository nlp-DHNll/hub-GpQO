# 中国神华 ESG 月报 Agent

## 项目目标

制作一个面向 ESG 部门的 Python 命令行 Agent。用户输入月份后，Agent 自动搜集中国神华相关信息，生成可在本地核对的 ESG 月报草稿。

## 已确认需求

- **覆盖企业：** 中国神华。
- **报告对象：** 企业 ESG 部门，兼顾管理层阅读。
- **月份输入：** 命令行接受 `YYYY-MM` 格式，省略时使用上一个完整自然月。只接受已结束的自然月，格式错误、当月或未来月份在搜索前提示。首次演示使用 2026 年 10 月数据。
- **信息来源：** 政府与监管机构、标准发布机构、中国神华及对标企业公告、可靠行业新闻。
- **资料筛选：** 分主题搜索，合并明显重复的报道，优先采用原始来源。某个主题资料不足时，更换关键词补搜一次。只有能确认发布时间在目标月内的资料才进入正文。
- **报告内容：**
  1. 摘要。
  2. ESG 政策、评级与标准动态。
  3. 行业新闻与最佳实践。
  4. 中国神华动态及 ESG 影响与建议。
  5. 对标企业的 ESG 关键行动。
  6. 来源清单。
- **对标企业：** 每期根据煤炭、电力业务的可比性选取 2–3 家，并在报告中说明选择依据。有可靠资料的企业不足两家时，按实际情况呈现。
- **报告格式：** 中文 Markdown。关键事实附来源名称、发布时间和链接，缺少可靠资料的章节注明证据缺口。
- **进度与重试：** 命令行显示搜索、筛选、生成、评价、调整和保存的进度。失败时提示具体环节，用户可重新运行命令。
- **资料不足与运行失败：** 部分章节有可靠资料时继续生成，并标明资料缺口。所有章节均无可靠资料，或 API 故障导致流程中断时，结束本次运行，提示原因和重试方式。
- **审核与历史：** 生成后在命令行显示保存路径。用户打开本地报告、核对引用链接，并通过 `reports/` 查阅历史版本。

## 技术实现

- **应用形态：** 本地 Python 命令行程序。开发和验收使用 Conda 环境 `py312`（Python 3.12）。
- **大模型服务：** DeepSeek API，通过 OpenAI SDK 接入。
- **生成方式：** 用户手动运行命令触发生成。
- **信息检索：** 汇总 DDGS、国家能源局、生态环境部、国家发展改革委、ISSB、上交所和港交所七个入口。各入口独立查询，无需搜索 API 密钥。引用前核验公开 HTML 原文及其发布日期。
- **报告保存：** Markdown 文件保存在项目本地 `reports/` 目录。文件名包含报告年月和生成时间，同月多次生成保留各版本。
- **运行日志：** 独立的 `RunLogger` 将步骤、评价和运行结果写入 `logs/<run_id>.jsonl`。首行记录运行开始时间，各步骤结束时记录耗时。
- **模型配置：** DeepSeek 服务地址、密钥和模型名称放在本地 `.env` 中。
- **技术方案状态：** 已确认。

## Agent 流程

**搜索 → 筛选 → 生成初稿 → 评价内容 → 评价可读性 → 保存报告**

搜索、筛选和补搜完成后生成一份初稿。任一评价未通过时，调用整体调整步骤，按该项评价的反馈修改后复评。

1. **内容评价。** 检查章节是否齐全、关键事实是否有来源、资料发布日期是否在目标月份。资料缺口如实标注后，仍可通过内容评价。内容未达标时，按反馈修正并复评内容。内容通过后进入可读性评价。
2. **可读性评价。** 检查摘要是否突出重点、章节是否连贯、表述是否清楚、内容是否重复。未通过时，根据反馈调整对应的段落、标题或衔接，再复评可读性。调整时保留已核对的事实、数字、结论和引用。
3. **保存报告。** 可读性评价通过即保存当前版本。

内容修正和可读性修正共用最多 5 轮。每次调整并复评算 1 轮，两类评价的首次检查不占修正轮数。用完修正额度后仍未通过当前评价时，终端显示剩余问题和修改建议，本次不保存报告。

## 运行环境

在已初始化 Conda 的终端运行 `conda activate py312`，再进入项目目录执行下方的 Python 命令。也可在项目目录直接通过 Anaconda 的 Python 调用 Conda：

```shell
python -m conda run -n py312 --no-capture-output python -X utf8 main.py 2026-10 --offline
```

各阶段的运行命令和验收方式见[开发检查点](docs/checkpoints.md)。

正式生成时，在 `.env` 配置 `DEEPSEEK_API_KEY`，并在 `py312` 环境运行 `python main.py 2026-10`。
