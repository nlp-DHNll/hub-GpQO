# 楼道消防隐患识别

一个手机优先的多模态网页应用。网页可直接拍摄楼道照片或从相册选择图片，后端调用 DeepSeek `deepseek-flash` 识别场景，并给出风险等级、判断依据和处理建议。

> 识别结果用于辅助巡查，不能代替消防专业检查。照片模糊、遮挡或不确定时，请以现场人工核查为准。

## 风险分类

| 分类 | 规则 |
| --- | --- |
| 高风险 | 楼道中出现电动车、电瓶、飞线充电等可能引发火灾的因素。 |
| 中风险 | 大量堆物严重影响通行，或大量纸箱、木质家具等可燃物形成明显堵塞。 |
| 低风险 | 有楼道堆物现象，但数量不多或影响不严重。 |
| 无风险 | 确认是楼道，且干净、没有堆放物。 |
| 非楼道 | 图片明显属于其他场景，或无法确认是楼道。 |

## 环境要求

- Python 3.10 或更高版本。
- 一个可用的 DeepSeek API Key。
- 手机访问时，手机与运行服务的电脑连接同一个局域网。

## 安装与启动

在项目目录中打开 PowerShell，执行：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

编辑 `.env`，将 `DEEPSEEK_API_KEY` 替换为你的真实密钥。其余配置默认即可：

```dotenv
DEEPSEEK_API_KEY=你的DeepSeek_API_Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

启动服务：

```powershell
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

电脑浏览器访问 <http://127.0.0.1:8000>。

## 手机访问

1. 确认手机和电脑连接同一个 Wi-Fi。
2. 在电脑上查看局域网 IPv4 地址：运行 `ipconfig`，找到当前 Wi-Fi 网卡下的“IPv4 地址”。
3. 在手机浏览器打开 `http://电脑的IPv4地址:8000`，例如 `http://192.168.1.20:8000`。
4. 点击“拍照”调用手机后置摄像头，或点击“相册”选择已有照片，再点击“开始识别”。

如果手机无法打开页面，确认电脑防火墙允许 Python/Uvicorn 在专用网络上通信，并确认两台设备在同一局域网。部分浏览器可能限制非 HTTPS 页面访问摄像头；此时可使用“相册”选择照片，或在支持的浏览器中访问。

## 图片与密钥

- API Key 仅由服务端从 `.env` 读取，不会下发到网页。
- 单张图片限制为 10 MB；后端检查图片格式、像素尺寸并转成 JPEG 后发送给模型。
- 服务限制每个客户端每分钟最多 10 次识别，并同时处理最多 2 次模型调用，减少误操作或局域网内重复请求带来的费用。
- 转换后的图片只在当前请求内存中处理，不写入磁盘或建立识别历史。
- 图片会发送至 DeepSeek API 进行模型识别；请勿上传包含不必要个人信息的照片，并按你的组织要求使用第三方模型服务。
- 为手机提供局域网访问时，同一网络中的其他设备也能访问网页；请只在可信任的 Wi-Fi 网络中运行，并关闭服务以停止访问。频率限制是单进程内的基础保护，不等同于账号认证。
- `.env` 已加入 `.gitignore`，不要把密钥复制到源码、网页或公开仓库。

## 常见问题

**提示尚未配置 API Key**：确认 `.env` 位于项目根目录、变量名为 `DEEPSEEK_API_KEY`，然后重启服务。

**DeepSeek 服务暂不可用**：检查网络、API Key 是否有效、账户是否可调用该模型；稍后可重新识别。

**图片格式不支持或图片无法读取**：选择 JPEG、PNG 或 WebP 图片，且大小不超过 10 MB。

**手机打不开摄像头**：优先尝试“相册”入口；移动浏览器对非 HTTPS 页面的摄像头访问可能有限制。

**结果要求人工复核**：照片可能模糊、遮挡或不是楼道场景；请现场确认，不要把模型提示当作安全结论。
