## 术语表

| 术语 | 含义 |
|---|---|
| **chunk（检索块）** | 文档切分后的最小检索单元，由多个连续版面块合并而成 |
| **版面块（block）** | MinerU 解析输出的原子元素：text / image / table / equation |
| **caption** | 用 Qwen3-VL 为图片生成的 1~2 句描述，使图片内容可被关键词检索 |
| **图文交替** | Prompt 中图片紧贴其所属 chunk 文字，而非集中放在末尾 |
| **citation（引用）** | 答案中指向某张图/某页的标记，前端渲染为引用卡片 |
| **RRF** | Reciprocal Rank Fusion，多路检索结果的排名融合算法 |
| **幂等键** | `doc_id` / `chunk_id`，保证 Kafka 消息重放不产生重复数据 |
| **DLQ** | Dead Letter Queue，死信队列 |
| **KRaft** | Kafka 不依赖 ZooKeeper 的元数据管理模式 |
| **base64 data URL** | `data:image/png;base64,xxx` 形式的内联图片，用于传给 vLLM |
