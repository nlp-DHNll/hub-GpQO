
## 1. 各源文件作用
```bash
01-intent-classify/
├── main.py              ← FastAPI 入口,定义 4 个意图分类接口
├── config.py            ← 全局配置(规则 / 模型路径 / LLM 信息)
├── data_schema.py       ← Pydantic 定义数据指定格式(请求/响应)
├── logger.py            ← 日志初始化(控制台 + 文件)
├── model/               ← 各分类算法的推理封装
│   ├── regex_rule.py    ← 正则规则匹配
│   ├── tfidf_ml.py      ← TFIDF + LinearSVC 加载与推理
│   ├── bert.py          ← BERT 模型加载与推理
│   └── prompt.py        ← 大模型(Qwen-plus) + Few-shot
└── training_code/       ← 模型训练脚本
    ├── train_tfidf.py   ← 训练 TFIDF + SVM
    └── train_bert.py    ← 微调 BERT 中文分类模型
```

## 2. FastAPI 请求到响应的全流程

### 2.1 主链路流程图

```mermaid
flowchart TD
    A([客户端]) --> B["HTTP POST /v1/text-cls/<br/>regex | tfidf | bert | gpt"]
    B --> C["FastAPI找到对应接口"]
    C --> D["Pydantic 解析 JSON Body<br/>→ TextClassifyRequest"]
    D --> E["计时和输出日志:<br/>start_time = time.time()<br/>logger.info(req)"]
    E --> F["构造 TextClassifyResponse<br/>默认值实例"]
    F --> G{"调用接口对应的实现方法"}
    G -->|成功| H["response.classify_result<br/>= 模型返回值"]
    G -->|异常| I["response.classify_result = ''<br/>response.error_msg = traceback"]
    H --> L
    I --> L["FastAPI 把 Response<br/>序列化为 JSON"]
    L --> M(["客户端收到响应"])
```

### 2.2 四个分类后端的差异化分支

```mermaid
flowchart LR
    REQ[req.request_text] --> ROUTE{选择哪条路由?}
    ROUTE -->|/v1/text-cls/regex| R["model_for_regex"]
    R --> R1["判断输入内容为str还是list"]
    R1 --> R2["re.findall 正则匹配"]
    R2 --> OUT1["返回 类别 或 Other"]

    ROUTE -->|/v1/text-cls/tfidf| T["model_for_tfidf"]
    T --> T1["判断输入内容为str还是list"]
    T1 --> T2["jieba.cut → 去停用词"]
    T2 --> T3["tfidf.transform(text)"]
    T3 --> T4["LinearSVC.predict → 类索引"]
    T4 --> OUT2["返回 类名 列表"]

    ROUTE -->|/v1/text-cls/bert| B["model_for_bert"]
    B --> B1["判断输入内容为str还是list"]
    B1 --> B2["tokenizer 编码request_text"]
    B2 --> B3["数据预处理"]
    B3 --> B4["模型评估"]
    B4 --> OUT3["返回 类名"]

    ROUTE -->|/v1/text-cls/gpt| G["model_for_gpt"]
    G --> G1["判断输入内容为str还是list"]
    G1 --> G2["将原始文本转换成 TF-IDF 特征向量"]
    G2 --> G3["设置动态提示词"]
    G3 --> G4["调用大模型API"]
    G4 --> OUT4["返回大模型输出结果"]
```
