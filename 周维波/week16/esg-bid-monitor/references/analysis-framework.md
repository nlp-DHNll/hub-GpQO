# 招投标汇总分析框架与口径

## 1. 金额分档口径（脚本固定）
| 分档 | 区间 |
| --- | --- |
| 小型 | < 10 万元 |
| 中型 | 10 ~ 30 万元 |
| 大型 | 30 ~ 100 万元 |
| 重大 | ≥ 100 万元 |
| 未披露 | 公告未给出金额，不参与金额均值/合计计算 |

## 2. 分析维度
- **品类结构**：各品类项目数量、金额合计、单价区间，判断需求最集中的服务类型。
- **客户类型**：金融机构 / 政府及事业单位 / 企业的采购规模与偏好。
- **地区分布**：项目数量与金额的区域集中度。
- **供应商格局**：头部中标方的中标次数、合计金额与品类覆盖，判断集中度。
- **时间趋势**：按月/季度项目数与金额变化，识别需求升温或降温方向。
- **单价对标**：同类项目报价区间，为预算编制与投标报价提供参照。

## 3. 历史汇总报告结构
1. 概览：样本量、金额披露率、合计/均值/中位数/区间。
2. 金额分档分布与单价区间。
3. 品类、客户类型、地区、供应商聚合结果。
4. 趋势与热点研判（Agent 结合数字撰写）。
5. 附录：条目清单（项目、采购人、供应商、金额、日期、地区、链接）。

## 4. 每日监控推送结构
- 当日新增条目（按相关度排序）：项目、采购人、供应商/待定、金额、地区、日期、命中标签、链接。
- 标注与历史库重复剔除数量；对高相关度条目附推荐理由（对应品类与潜在机会）。

## 5. 数据纪律
- 未披露金额不估算、不补全；占比分母注明样本量。
- 中标结果与招标公告分开统计；汇总分析以中标结果为准。
- 跨地区/跨品类对比时注明口径差异；样本量过小（如某档仅 1~2 条）不下趋势结论。
- 所有结论可回溯到附录条目与官方链接。
