1、 langchain 工具调用 和 llm function call 有什么区别？
langchain 面向用户侧提供了统一的编码格式可以适配不同的大模型，langchain将封装转化后的信息传递给大模型，并在模型输出结果后，将结果传递给用户；在业务流程中langchain定位为中间件，起到承上启下的作用，简化了用户侧的工作。它自身并不具备直接工具调用的能力。

2、 langchain 工具调用 的 速度是受到什么影响？
从调用速度上分析，langchain 和 llm function call 调用速度，耗时没有什么区别；langchain只是把用户的输入进行封装后，传递给大模型，对比大模型调用工具只多了一个封装的动作。影响langchain工具调用速度的本质上还是大模型自身的推理，工具响应执行，模型输出回复 这几部分的耗时。
