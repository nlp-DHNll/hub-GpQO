  🚀 使用方式

  # 1) 安装依赖
  pip install -r requirements.txt

  # 2) 启动 Neo4j(必须)
  docker run -d -p 7687:7687 -p 7474:7474 -e NEO4J_AUTH=neo4j/password neo4j

  # 3) 设置 DeepSeek Key(必须)
  export DEEPSEEK_API_KEY=sk-xxxxxxxx

  # 4) 灌库
  python scripts/init_neo4j.py

  # 5) 启动
  python main.py                # CLI 交互
  streamlit run web/app.py      # Web UI
  python main.py --eval         # 跑评估
  pytest tests/ -v              # 跑测试

  🔧 关键设计亮点

  - 严格依赖:Neo4j 或 DeepSeek Key 缺失时启动即报错并打印修复指引
  - 规则+模型双轨:模型未训练时规则兜底,永远可运行
  - 长关键词优先匹配:降低短关键词的误匹配
  - 上下文继承:多轮对话中实体自动跨轮传递
  - 业务策略注入:退换货/物流等场景的模板话术
