作业1: 安装langchain 和 openai-agent，运行 langchain / 02_Model工具调用.py
    回答如下问题：

        1、 langchain 工具调用 和 llm function call 有什么区别？
            区别：
                langchain 工具调用，它是封装框架层完整流程，它是面向应用开发框架封装出来的，但底层大部分场景仍依赖 llm function call；
                面llm function call 它是大模型原生能力，没有执行逻辑、循环和工具管理；
                langchain 工具调用，可以内置tool 进行统一管理工具入参，描述等

        2、 langchain 工具调用 的 速度是受到什么影响？
            它的调用速度受到如下几个方面影响：
                2.1 它受到大模型本身推理的速度影响
                2.2 问题的复杂度，它可能需要agent 多次调用来计算出结果
                2.3 本地网速或 LLM 厂商网络影响
                2.4 调用第三方服务，可能被限流或相关约束影响

     到返回结果的流程，绘制流程图（手绘、自然语言表达）。

    main.py 中存在四种文本分类的API,分别是：
        /v1/text-cls/regex (regex_classify), # 利用正则表达式进行文本分类
        /v1/text-cls/tfidf (tfidf_classify), # 利用TFIDF进行文本分类
        /v1/text-cls/bert  (bert_classify),  # 利用BERT进行文本分类
        /v1/text-cls/gpt  (gpt_classify)     # 利用大语言模型进行文本分类
        在四个API 中都有统一的异常处理，统一的请求对象：TextClassifyRequest，返回最终的分类结果（TextClassifyResponse 类型），还有分类时间的统计
    
    然后，每一个API 服务，都有具体的实现 ./model/ 目录下的4个文件：bert.py , prompt.py regex_rule.py, tfidf_ml.py
    
    data_schema.py 定义了4个API 的请求和响应对象（请求格式和返回格式）
