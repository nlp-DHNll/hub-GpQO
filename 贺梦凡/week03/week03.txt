1. langchain 工具调用 和 llm function call 有什么区别？
（1）LLM Function Call是模型本身提供的能力。OpenAI等厂商在 API 里定义了一种特殊字段，让模型能"决定调用某个函数并生成参数"，但只负责输出结构化的调用请求，不负责执行。LangChain可以跨厂商统一化、自动生成 schema、标准化解析
（2）用 @tool 装饰器自动从函数签名+docstring 提取 schema，不用手写 JSON schema，在请求时自动带上tools字段
2.  langchain 工具调用 的 速度是受到什么影响？
（1）调用模型推理时长，模型需要理解用户意图，判断是否调用工具、调用哪个工具、参数是什么。提示词中工具描述越多，推理时间越长
（2）工具自身执行时长，调用API、查询数据库等操作很耗时
