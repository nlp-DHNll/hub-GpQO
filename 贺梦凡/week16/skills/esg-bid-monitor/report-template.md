# 两年汇总模板

标题文字保持不变。交付稿不要抄本页说明。`### 脚本统计` 下面整段使用 `analyze_bids.py` 的标准输出，不要手改其中的数字。

```markdown
# ESG与双碳中标信息汇总（{YYYY-MM-DD} 至 {YYYY-MM-DD}）

## 报告信息

- 信息窗口：YYYY-MM-DD 至 YYYY-MM-DD（含首尾）
- 编制日期：YYYY-MM-DD
- 样本定义：ESG、可持续发展、双碳相关的公开招标、采购意向、候选人公示、中标和成交公告
- 金额口径：只统计中标公告和成交公告里写明的中标金额或成交金额

本报告是公开网络样本，不是全国招标全量统计。

## 执行摘要

5 到 8 条。样本少于 15 条时，第一条写明样本不足。

- 见脚本统计：……｜[来源名](url)

## 一、口径与样本

写纳入词、排除了哪几类项目、实际检索了哪些平台、详情页打开失败的数量。

## 二、热点招标主题

解释脚本统计里项目数靠前的主题：买方是谁、采购的是报告、核查、系统还是咨询，以及这和双碳合规的哪一项义务有关。每个判断都要回到某一条公告。

## 三、中标金额分布

### 脚本统计

{粘贴 analyze_bids.py 的全部标准输出}

### 怎么读这些数字

披露率、分档、中位数分别说明什么。金额未披露的项目不得被说成「小项目」。把预算误当成中标金额的情况要在这里纠正。

## 四、结构观察

按买方类型、地区和季度写观察。只描述脚本统计和明细表里看得到的集中或空缺。某地区项目少，先说明可能是平台没收录进公开网页，不要直接写成当地没有需求。

## 五、对业务的含义

给准备投这类标的团队 3 条可执行含义：哪类主题出现次数高、金额通常落在哪一档（必须是已披露样本）、常见采购人是政府、能源企业还是金融机构。每条指回脚本统计或一条公告。

## 信息缺口与检索说明

- 候选、入选、剔除和主要剔除原因
- 没能打开的平台
- 金额未披露的比例应如何限制结论

## 信源与明细附录

| 日期 | 文种 | 标题 | 采购人 | 中标人 | 金额原文 | 主题 | 链接 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| YYYY-MM-DD | 中标公告 |  |  |  | 128.6万元 / 未披露 |  | https://... |
```

# 每日推送模板

有新增时：

```markdown
# ESG招标日报 {YYYY-MM-DD}

检索窗口：{起始时间} 至 {结束时间}（Asia/Shanghai）
今日新增 {N} 条。以下只含台账中没有的公告。

## 1. {公告标题}

- 采购人：
- 发布日期：YYYY-MM-DD
- 地区：
- 预算或限价：未披露 / 原文金额
- 截止时间：未知 / YYYY-MM-DD
- 主题：
- 相关原因：原文「……」
- 链接：https://...
```

没有新增时只写：

```markdown
# ESG招标日报 {YYYY-MM-DD}

检索窗口：{起始} 至 {结束}（Asia/Shanghai）
今日无新增ESG相关招标。
```
