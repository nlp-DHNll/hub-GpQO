# ESG月报

## 任务要求

汇总过去一个月的时政信息帮客户生成ESG月报。需要至少包括以下几个部分内容：

1. ESG政策、评级、标准等相关的动态
2. 客户所属行业层面相关的新闻动态，最佳实践
3. 客户公司的一些动态对ESG影响和建议，对标企业的一些ESG关键行动

可以以中国神华为例。

## 先读再做

1. 读 [search-plan.md](search-plan.md)，按其中的画像、查询和信源层级执行。
2. 写正文前读 [report-template.md](report-template.md)。交付稿使用其中的标题原文，不要把填写说明抄进报告。

未指定客户时，客户用中国神华。未指定月份时，窗口取**上一个自然月**（含首尾两天）。用户指定「过去30天」或某个月份时，以用户为准，并在报告信息里写明起止日期。

## 工作流

复制并逐项完成：

```
进度：
- [ ] 确认客户、证券代码、行业、窗口、对标名单
- [ ] 用最新年报或官网核对客户画像，再决定行业检索角度
- [ ] 按 search-plan 的最低查询集检索，并顺着一手文件追下去
- [ ] 打开将要引用的原始页面，核对名称、日期和数字
- [ ] 按五分量表筛选，写明入选数和剔除数
- [ ] 按模板写报告，执行摘要最后写
- [ ] 运行检查脚本，有失败就改到通过
- [ ] 保存报告并交给用户
```

## 检索

先跑确定性脚本，再读它写出的 JSON。脚本负责固定查询、打开页面、抽取原句和五项打分。模型只在「入选」条目上写对客户的含义和建议。脚本没打开的搜索摘要不能写成事实。

```bash
python "{baseDir}/scripts/web_digest.py" --client 中国神华 --since YYYY-MM-DD --until YYYY-MM-DD --out reports/esg-monthly/digest.json
```

`{baseDir}` 只在 OpenClaw 中展开。别处换成这个技能目录。入选条件在脚本里是固定的：页面已打开、日期不在窗口外、五项总分不低于 5、摘句能在原文里逐句找到。入选为空时，正文写未检索到够格条目，并附上脚本列出的失败原因。要补查询就追加 `--query` 再跑一遍。

脚本整段失败，或报「没有一条标题或摘要含查询词」时，改用环境自带的网页搜索拿到地址，再把地址交回脚本抽取。OpenClaw 用 `web_search` 和 `web_fetch`；Cursor 用网页搜索和页面抓取。

```bash
python "{baseDir}/scripts/web_digest.py" --since YYYY-MM-DD --until YYYY-MM-DD --url <页面地址> --out reports/esg-monthly/digest.json
```

有时间范围参数时设为任务窗口，否则把年月写进查询词。模型仍然只写含义和建议。

- 政策名称、评级变动、罚款、排放、资本开支、装机、碳价：必须打开原始页面后才能写入。搜索摘要不能单独作为这些事实的依据。
- 同一事实只保留最早的一手来源。通讯社转载、门户转载删掉。
- 窗口内没有够格材料时，在对应小节写「本窗口未检索到够格条目」，并写已用过的查询。禁止用训练记忆里的旧闻填满正文。
- 框架性背景（例如某项准则仍然有效）若本轮没打开原文，句首标明「未在本轮检索中复核」，并且只能放进「仍有效的框架」或「窗口外对标」。
- 先跑完 search-plan 的最低查询集，再根据已发现的文件名、文号、评级动作追加检索。最低查询集没跑完，不得开始写正文。

## 筛选

每条候选按 0–2 分打五项：权威、相关、新颖、重大、可行动。细则在 search-plan.md。**总分低于 5 的不进正文。**

入选后仍要压缩：政策与标准最多 8 条，行业新闻最多 6 条，最佳实践最多 4 条，客户动态最多 6 条。宁肯写透少数重大事项，不要做新闻剪报。最佳实践必须写清做法、可核对的效果、以及客户能不能迁过来。

## 写作

正文用中文，面向客户的董事会办公室和安环/战略部门。

- 事实句式：`- YYYY-MM-DD｜发生了什么｜对这家客户的含义｜[来源名](url)`
- 含义只能写成合规、资金成本、许可与安全、碳成本、声誉、可迁移做法中的一类或几类。
- 建议句式：`- 【高｜短期】谁在什么时限内做什么。依据：上文哪一条已注明来源的事实。`
- 优先级只用「高、中、低」，时限只用「短期、中期」。短期不超过一个季度。
- 每条建议都要能指回一条带来源的事实。禁止「加强ESG管理」「持续关注政策」这类没有动作和责任主体的句子。
- 执行摘要 5 到 8 条，全部来自正文，最后再写。
- 对标表至少 3 家企业。窗口内没有可核实行动时，该格写「窗口内未检索到可核实的ESG关键行动」，不要用旧记忆补。

格式示例（下面的日期和政策是虚构的，禁止写入正式报告）：

```
- 2099-01-15｜示例交易所发布一份虚构通知｜合规：先核对客户是否进入强制样本｜[示例来源](https://example.com/notice)
```

差的句子（禁止出现同类表述）：「近期国家高度重视ESG，企业应加强信息披露。」

## 交付前检查

把报告存到 `reports/esg-monthly/YYYY-MM-客户简称.md` 后运行：

```bash
python "{baseDir}/scripts/check_report.py" "reports/esg-monthly/YYYY-MM-客户简称.md"
```

`{baseDir}` 只在 OpenClaw 中会展开。在 Cursor 或普通终端里，把 `{baseDir}` 换成这个技能目录。`python` 不可用时改用 `python3`。

脚本失败就改报告，再跑，直到输出 `OK`。通过之前不要把报告交给用户。通过之后，在对话里给出报告全文路径，并附上 5 到 8 条执行摘要。
