# ESG月报模板

标题文字保持不变。交付稿不要包含本页的说明，不要留下「填写」「待补充」。

```markdown
# {客户简称} ESG月报（{YYYY-MM-DD} 至 {YYYY-MM-DD}）

## 报告信息

- 客户全称：
- 证券代码：
- 所属行业：
- 信息窗口：YYYY-MM-DD 至 YYYY-MM-DD（含首尾）
- 编制日期：YYYY-MM-DD
- 对标企业：
- 画像依据：{年报或官网名称}，[来源名](url)

## 执行摘要

5 到 8 条。每条都是正文里已经写过的事实或建议，并带来源链接。

- YYYY-MM-DD｜……｜[来源名](url)

## 一、ESG政策、评级与标准动态

### 1.1 本窗口动态

- YYYY-MM-DD｜事实｜对客户的含义（合规 / 资金成本 / 许可与安全 / 碳成本 / 声誉 / 可迁移做法）｜[来源名](url)

### 1.2 仍有效的框架

只放窗口外、但仍然约束客户的准则或法规。每条标明原始发布日期。没有则写：本栏无条目。

- YYYY-MM-DD｜框架名称仍有效｜为何本月还要单列｜[来源名](url)

### 1.3 对客户的影响

用表格，只收录上文出现过的事项。

| 事项 | 适用性 | 时间要求 | 建议动作 | 来源 |
| --- | --- | --- | --- | --- |
|  | 直接适用 / 可能适用 / 暂不适用 |  |  | [来源名](url) |

## 二、行业新闻与最佳实践

### 2.1 行业新闻

- YYYY-MM-DD｜事实｜和客户业务的关系｜[来源名](url)

### 2.2 最佳实践

每条回答：谁做了什么、效果数字出自哪里、客户能否迁移、迁移时要改什么。

- YYYY-MM-DD｜实践｜效果（带来源）｜可迁移性｜[来源名](url)

## 三、公司动态、ESG影响与对标行动

### 3.1 客户公司动态及ESG影响

- YYYY-MM-DD｜事实｜E / S / G 影响｜[来源名](url)

没有够格动态时写：本窗口未检索到够格条目。并列出用过的查询。

### 3.2 建议

至少 3 条。格式固定。

- 【高｜短期】{部门}在{时限}内{动作}。依据：{上文事实，含日期}。
- 【中｜中期】……。依据：……。
- 【低｜中期】……。依据：……。

### 3.3 对标企业ESG关键行动

至少 3 行数据。窗口内没有行动的企业也保留一行。

| 对标企业 | 窗口内关键行动 | 日期 | 可核验证据 | 相对客户的启示 |
| --- | --- | --- | --- | --- |
|  |  | YYYY-MM-DD | [来源名](url) |  |

### 3.4 窗口外对标

只放窗口稍早、但确有借鉴价值的行动，并说明为何破例。没有则写：本栏无条目。

- YYYY-MM-DD｜行动｜破例原因｜[来源名](url)

## 信息缺口与检索说明

- 候选条数、入选条数、剔除条数、主要剔除原因
- 打开失败的重要页面
- 未能核对的数字（不要在正文里写成确定事实）

## 信源附录

| 序号 | 日期 | 标题 | 层级（A/B） | 链接 |
| --- | --- | --- | --- | --- |
| 1 | YYYY-MM-DD |  | A | url |
```
