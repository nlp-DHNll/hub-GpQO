# ESG 报告质量检查清单

## 结构

- [ ] 7 个必备部分齐全，标题层级正确
- [ ] 每个事实性段落带来源编号 `[n]`
- [ ] 来源表包含标题、日期、机构、等级、URL
- [ ] 检索式清单可复现

## 证据

- [ ] 时间窗内明确日期 >= 3 个
- [ ] 有效来源 >= 12 条，覆盖政策/行业/客户/对标四类
- [ ] A/B 级来源占比 >= 50%
- [ ] 数字与原文一致，单位与口径未变
- [ ] 冲突信息已并列说明

## 分析

- [ ] 影响判断标注 E/S/G 维度与方向
- [ ] 建议具体到动作、部门、时间
- [ ] 客户事实与对标事实未混淆
- [ ] “未见披露”未被写成“不存在”

## 脚本验证失败修复

| 问题 | 修复动作 |
|------|----------|
| 链接数不足 | 补做检索，优先 A 级来源；在来源表补齐 URL |
| 缺章节关键词 | 按 outline 增加对应小节标题 |
| 时间窗外日期过多 | 将背景信息移入“背景”小节并标注日期 |
| 存在占位符 | 全部替换为真实内容或“未见披露” |
| 数字不足 | 从证据表补入可核验数字，不新增推测 |
