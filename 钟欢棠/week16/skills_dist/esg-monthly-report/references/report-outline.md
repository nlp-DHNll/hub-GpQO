# ESG 月报结构规范

## 必备结构

1. **封面信息**：报告名称、客户、时间窗、生成日期、编制方式（Skill 名称+检索工具）。
2. **本月概览**：3–5 条核心判断，每条一句话+来源编号+日期，按重要性排序。
3. **ESG 政策、评级与标准动态**：按“监管政策 / 评级方法 / 披露标准 / 国际规则”分组；每条含事件、关键内容、对客户影响、来源。
4. **行业新闻与最佳实践**：按 E/S/G 或技术/管理/披露分组；提炼“做法—效果—可借鉴点”。
5. **客户公司动态与 ESG 影响**：逐条标注 E/S/G 维度、影响方向（正面/中性/风险）、影响程度（高/中/低）、建议动作。
6. **对标企业关键行动**：对照表（企业、行动、披露亮点、客户差距、可复制做法）。
7. **风险提示与下月关注清单**：监管日程、评级窗口、披露节点、行业事件。
8. **附录**：检索式清单、来源表（编号/标题/日期/来源/等级/URL）、方法说明与局限。

## 表述标准

- 事实句：`……（据XX，YYYY-MM-DD）[n]`。
- 分析句：以“判断：”“建议：”开头，明确属于推断。
- 数字：保留原文口径与单位，换算时同时给出原值与换算值。
- 缺失：`公开渠道未见披露`，禁止留空或杜撰。
- 每条建议必须可执行：动作 + 责任部门建议 + 时间建议。

## 质量红线

- 不得把检索摘要当作已核实全文；
- 不得把行业事件写成客户事件；
- 不得把“获奖”直接等同于“ESG绩效改善”，需结合证据说明；
- 对标企业信息必须给出同期或最近一期可核验来源。
