# 招投标报告质量检查清单

## 数据

- [ ] 记录数与明细表一致，去重后无重复项目
- [ ] 金额统一为万元，单位换算抽查 >= 5 条
- [ ] 预算金额未混入中标金额
- [ ] 未披露金额单独计数，不参与均值
- [ ] 每条记录有来源链接与公告日期

## 分析

- [ ] 热点主题、金额分布、中标单位格局三块齐全
- [ ] 时间趋势注明样本局限
- [ ] TOP 项目与统计表数字一致
- [ ] 建议基于样本事实，不夸大市场结论

## 每日监控

- [ ] state 文件存在且被更新
- [ ] 重复运行同一输入无重复推送
- [ ] 无新增时明确写明“今日无新增”
- [ ] 推送含链接、日期、摘要

## 脚本验证失败修复

| 问题 | 修复动作 |
|------|----------|
| 链接不足 | 补充 A 级公告来源，明细表补齐 URL |
| 缺章节关键词 | 按模板补齐“热点/金额/监控/来源”小节 |
| 数字不足 | 从统计 JSON 补入可核验数字 |
| 占位符 | 替换为真实内容或“未披露” |
