# 月报的产物格式

报告骨架、证据表与运行记录的模板。运行产物契约的权威说明在 `邓帅/week16/tools/readme.md`，本文件是其中月报部分的摘录，两者不一致时以它为准。

## 报告骨架 `report.md`

把尖括号里的内容换成实际值，括号里的提示写完后删掉。

```markdown
# <客户> ESG 月报（<起始日期> 至 <结束日期>）

- 客户：<客户>
- 行业：<行业>
- 时间窗：<起始日期> 至 <结束日期>（N 天）

## 一、摘要与本月要点

（三到五条本月要点，每条句末带角标）

## 二、政策/评级/标准动态

### 2.1 政策

### 2.2 评级

### 2.3 标准

## 三、行业新闻与最佳实践

## 四、<客户>公司动态：影响与建议

### 4.1 本期公司动态

### 4.2 影响与建议

| 序号 | 建议 | 依据 |
|---|---|---|
| 1 | （针对客户具体情况的建议） | [n] |

### 4.3 对标企业关键行动对比表

（先写一段：按哪三条规则选的、各家的理由）

| 对标企业 | 关键行动 | 披露情况 | 来源 |
|---|---|---|---|
| （企业名） | （时间窗内或最近一次披露的行动） | （出自哪份报告） | [n] |

## 五、下月关注清单

| 序号 | 关注事项 | 关注理由 |
|---|---|---|
| 1 | （下月该盯的事） | （为什么，带角标） |

## 六、方法与来源说明

（查询矩阵的执行情况与搜索次数；来源构成：各级来源数、中英文比例；局限）

## 七、待核实事项

| 序号 | 事项 | 线索来源 | 未核实的原因 |
|---|---|---|---|
| 1 | （线索） | [n] | （为什么没核实） |

（没有待核实项就写一句「本期无待核实事项」）

## 八、证据表附录

| 角标 | 所属章节 | 支撑的结论 | 来源 | 发布日期 | 原文摘录 | 可信度分级 | 核实状态 |
|---|---|---|---|---|---|---|---|
| 1 | 政策/评级/标准动态 | （一句话） | [来源名](https://…) | 2026-11-24 | （逐字摘录，不超过 50 字） | 二级 | 已核实 |
```

章节靠标题里的关键词识别，标题里的这些词不能省：

| 章节 | 标题须含有 |
|---|---|
| 摘要与本月要点 | 摘要、要点 |
| 政策/评级/标准动态 | 政策、评级、标准 |
| 行业新闻与最佳实践 | 行业、最佳实践 |
| 客户公司动态的影响与建议 | 公司动态、建议 |
| 下月关注清单 | 关注、清单 |
| 方法与来源说明 | 方法、来源 |
| 待核实事项 | 待核实 |
| 证据表附录 | 证据表 |
| 对标企业关键行动对比表 | 对标、对比，且是一张表格 |

每个章节都要有内容（可以写在它的小节里）。角标写在事实句末：`……新规要求……[1]`；`[1](https://…)` 这样的链接不算角标。
可信度分级在附录里写「一级 / 二级 / 三级」，核实状态写「已核实 / 仅见摘要 / 已排除」。

## 证据表 `data.json`

顶层是对象，证据放在 `evidence` 数组里。每条八个字段都要有，不要删字段。取不到的写 `null` 只适用于 `published_at`；`quote` 只有「已排除」的证据可以为空；其余六项必填。

| 字段 | 含义 | 要求 |
|---|---|---|
| `id` | 角标编号 | 正整数，整张表不重复 |
| `section` | 所属章节 | 用章节名，如 `政策/评级/标准动态`、`行业新闻与最佳实践`、`中国神华公司动态：影响与建议`、`待核实事项` |
| `claim` | 支撑的结论 | 一句话 |
| `url` | 来源地址 | 读过的那一页 |
| `published_at` | 发布日期 | 原文页面上的日期，统一写成 `2026-11-24` 这样的形式；页面不显示日期就写 `null` |
| `quote` | 原文摘录 | 逐字取自原文，不超过 50 字；只有「已排除」的证据可以为空 |
| `credibility_tier` | 可信度分级 | `1`、`2`、`3` |
| `verification` | 核实状态 | `verified`（已核实）、`summary-only`（仅见摘要）、`excluded`（已排除） |

```json
{
  "evidence": [
    {
      "id": 1,
      "section": "政策/评级/标准动态",
      "claim": "省级节能降碳方案把煤电列入重点行业",
      "url": "https://finance.sina.com.cn/esg/2026-11-24/doc-xxxxxxxxxxxx.shtml",
      "published_at": "2026-11-24",
      "quote": "聚焦钢铁、水泥、煤电等7个重点行业",
      "credibility_tier": 2,
      "verification": "verified"
    },
    {
      "id": 2,
      "section": "待核实事项",
      "claim": "线索：七部门发文推进石化化工老旧设备更新",
      "url": "https://www.example.com/news/1",
      "published_at": null,
      "quote": "加力推进石化化工行业老旧设备更新改造",
      "credibility_tier": 3,
      "verification": "summary-only"
    }
  ]
}
```

## 运行记录 `run.json`

无头运行由运行器生成，不要自己写。在交互会话里运行时，照下面的模板自己写一份，放在运行目录里：

```json
{
  "run_id": "20261127-手动-monthly",
  "case": "monthly-report",
  "mode": "report",
  "version": "noscript",
  "skill_version": "esg-monthly-report@0.1.0",
  "client": "中国神华",
  "industry": "煤炭·能源",
  "time_window": {"start": "2026-10-28", "end": "2026-11-26"},
  "model": "glm-5.4",
  "started_at": "2026-11-26T10:00:00+08:00",
  "duration_ms": null,
  "input_tokens": null,
  "output_tokens": null,
  "cost_usd": null,
  "search_count": 12,
  "invocation": "interactive"
}
```

`time_window` 是本次实际使用的起止日期；`search_count` 填你实际搜索的次数；取不到的用量字段填 `null`。
