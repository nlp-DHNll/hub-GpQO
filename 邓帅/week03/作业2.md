## 目录介绍

- assets 资源文件目录
    - dataset 训练数据集目录
        - baidu_stopwords.txt
        - dataset.csv
- docs 项目文档目录
- logs 存放各类日志
- model 不同分类方法的具体实现
- test 测试用例
- training_code tfidf 与 bert 分类模型的训练，会产出训练后的模型到 assets 目录下
- config.py 全局配置，企业项目会分多种，开发环境、测试环境、生产环境等等
- data_schema.py 数据模型定义，项目还比较简单，所以用一个文件就可以，复杂项目也是需要用独立目录进行组织
- fastapi_demp.py 看起来像是临时测试用的文件，没有引用关系
- logger.py 日志记录封装
- main.py 入口文件，里面定义了 fastapi 接口。正常复杂的企业项目应该用独立的模块组织 api，main 中只放初始化流程相关内容。

## API

收到请求后的处理流程基本一致，区别在 `model` 目录中不同方法处理流程的不同。请求处理：
- 记录时间
- 创建响应
- 根据请求信息，调用 bert 模型，获取结果并添加到响应
- 如果一切顺利，msg 设置为 ok，否则设置为错误原因
- 返回响应

### /v1/text-cls/regex
- 构建正则表达式
- `model_for_regex` 处理：定义一个函数，接收一个字符串或字符串列表，返回对应的分类结果
    - 输入为字符串时，
        历 `REGEX_RULE_COMPILED`，命中哪一类就把对应 category 加入结果
        - 都不命中则归为 "Other"
    - 输入为列表时，逐个文本做同样的匹配处理
    - 输入类型不支持时，抛异常交给外层捕获
    - 返回分类标签

### /v1/text-cls/tfidf
- 加载训练好的 tfidf 和分类模型（joblib `load`）
- 加载中文停用词表，用于过滤分词结果
- `model_for_tfidf` 处理：定义一个函数，接收一个字符串或字符串列表，返回对应的分类结果
    - 输入为文本
        - 使用 `jieba.lcut` 对输入做分词
        - 去掉停用词
        - 用空格拼接成 `query_words`
        - 通过 `tfidf.transform` 转换成向量
        - 调用 `model.predict` 得到分类结果
    - 输入为列表时，对每个文本依次做同样的处理，最后统一预测
    - 输入类型不支持时，抛异常交给外层捕获
    - 返回分类标签


### /v1/text-cls/bert
bert 模型处理（`from model.bert import model_for_bert`）：
- 确定设备类型
- 根据 `config.py` 中的模型信息，从 `assets/` 中加载模型
    - tokenizer，分词器
    - model，定义模型
    - 加载模型，`model.load_state_dict`
    - 设置试用设备
- `model_for_bert` 处理：定义一个函数，接收一个字符串或字符串列表，返回对应的分类结果
    - 将输入做标准化处理
    - 将输入进行分词
    - 构建数据集
    - 构建数据加载器
    - `model.eval()` 评估模式，关闭 Dropout 和 Batch Normalization 的训练行为，保证推理结果稳定
    - `pred = []` 初始化预测结果
    - 遍历数据集，进行预测
        - `torch.no_grad()` 进入纯计算模式
        - `input_ids`，输入序列
        - `attention_mask` 标记序列中哪些值是真实值，哪些是默认填充
        - `labels`，全 0 数组
        - 调用 `model` 获取输出
        - 获取预测结果，并转成 numpy 形式
        - `pred += list(np.argmax(logits, axis=1).flatten())`，取概率最大的作为预测结果
    - 根据预测结果从 `CATEGORY_NAME` 中获取真实标签
    - 返回分类标签


### /v1/text-cls/gpt
- 加载数据集
- 加载 tfidf 模型，用于动态构建提示词（few-shot）
- 创建 llm client
- 定义提示词模版
- `model_for_bert` 处理：
    - 对输入进行标准化处理，并获取 `tfidf_feat`（类似 encoding）
    - 对输入的迭代处理过程：
        - 计算与预训练 tfidf 矩阵的相似度
        - 取最高的 10 个 index
        - 通过 train_data 获取真实文本
        - 动态构建提示词
        - 调用 chat completion 接口
        - 获取分类标签，添加到 `classify_result`
    - 返回结果
